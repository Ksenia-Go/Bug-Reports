# BUG-01 — Не отображается изображение в блоке «Наш главный производитель»

| Параметр                  | Значение                                                                                                                                                                                                                                |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ID                    | BUG-01                                                                                                                                                                                                                                  |
| Заголовок             | Не отображается одно из изображений в блоке «Наш главный производитель» на главной странице                                                                                                                                             |
| Краткое описание      | Одно из изображений в блоке «Наш главный производитель» не отображается при переключении изображений                                                                                                                                    |
| Предусловие           | —                                                                                                                                                                                                                                       |
| Шаги воспроизведения  | 1. Открыть главную страницу сайта https://guru.qahacking.ru/ <br> 2. Прокрутить страницу вниз до блока «Наш главный производитель» <br> 3. Переключать изображения с помощью стрелки <br> 4. Найти изображение, которое не отображается |
| Фактический результат | Вместо одного из изображений отображается пустой блок.                                                                                                                                                                                  |
| Ожидаемый результат   | Каждое изображение в блоке «Наш главный производитель» отображается корректно при переключении.                                                                                                                                         |
| Severity              | Trivial                                                                                                                                                                                                                                 |
| Priority              | Low                                                                                                                                                                                                                                     |
| Окружение             | Windows 11 Pro, Яндекс Браузер 26.8.1.966                                                                                                                                                                                               |
