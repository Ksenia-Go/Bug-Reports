# BUG-04 — Некорректное переключение чекбокса при нажатии на текст

| Параметр                  | Значение                                                                                                                                                                                         |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ID                    | BUG-04                                                                                                                                                                                          |
| Заголовок             | При нажатии на текст одного чекбокса отметка устанавливается у другого                                                                                                                           |
| Краткое описание      | При нажатии на текст чекбокса в форме бронирования питомца отметка устанавливается у другого значения.                                                                                           |
| Предусловие           | —                                                                                                                                                                                                |
| Шаги воспроизведения  | 1. Открыть главную страницу сайта https://guru.qahacking.ru/ <br> 2. Перейти во вкладку «О нас» <br> 3. Прокрутить страницу вниз до формы бронирования питомца <br> 4. Нажать на текст «русский» при выборе языка |
| Фактический результат | Отметка устанавливается у значения, расположенного выше выбранного.                                                                                                                              |
| Ожидаемый результат   | При нажатии на текст чекбокса отметка устанавливается напротив соответствующего значения.                                                                                                        |
| Окружение             | Windows 11 Pro, Яндекс Браузер 26.8.1.966                                                                                                                                                        |
| Severity              | Minor                                                                                                                                                                                            |
| Priority              | Low                                                                                                                                                                                              |
