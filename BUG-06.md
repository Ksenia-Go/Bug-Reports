# BUG-06 — Вращение блока «Популярное» при прокрутке страницы

| Параметр                  | Значение                                                                                                                                                                                        |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ID                    | BUG-06                                                                                                                                                                                         |
| Заголовок             | Блок «Популярное» вращается при прокрутке страницы                                                                                                                                              |
| Краткое описание      | Содержимое блока «Популярное» начинает вращаться во время прокрутки страницы.                                                                                                                   |
| Предусловие           | —                                                                                                                                                                                               |
| Шаги воспроизведения  | 1. Открыть главную страницу сайта https://guru.qahacking.ru/ <br> 2. Перейти во вкладку «О нас» <br> 3. Прокрутить страницу вниз до блока «Популярное» <br> 4. Продолжить прокручивать страницу |
| Фактический результат | Содержимое блока «Популярное» вращается во время прокрутки страницы, из-за чего текст сложно прочитать.                                                                                         |
| Ожидаемый результат   | Содержимое блока «Популярное» остаётся неподвижным при прокрутке страницы, а текст отображается в удобном для чтения положении.                                                                 |
| Окружение             | Windows 11 Pro, Яндекс Браузер 26.8.1.966                                                                                                                                                       |
| Severity              | Minor                                                                                                                                                                                           |
| Priority              | Medium                                                                                                                                                                                          |
