# BUG-05 — Кнопка подтверждения не отображается без наведения курсора

| Параметр                  | Значение                                                                                                                                                                                                                             |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ID                    | BUG-05                                                                                                                                                                                                                              |
| Заголовок             | Кнопка «Подтвердить отправку» не отображается без наведения курсора                                                                                                                                                                  |
| Краткое описание      | Кнопка «Подтвердить отправку» становится визуально заметной только после наведения курсора.                                                                                                                                          |
| Предусловие           | —                                                                                                                                                                                                                                    |
| Шаги воспроизведения  | 1. Открыть главную страницу сайта https://guru.qahacking.ru/ <br> 2. Перейти во вкладку «О нас» <br> 3. Прокрутить страницу вниз до формы бронирования питомца <br> 4. В конце формы навести курсор на кнопку «Подтвердить отправку» |
| Фактический результат | До наведения курсора кнопка визуально не отображается. После наведения курсора кнопка становится видимой.                                                                                                                            |
| Ожидаемый результат   | Кнопка «Подтвердить отправку» отображается на странице без необходимости наведения курсора.                                                                                                                                          |
| Окружение             | Windows 11 Pro, Яндекс Браузер 26.8.1.966                                                                                                                                                                                            |
| Severity              | Minor                                                                                                                                                                                                                                |
| Priority              | Medium                                                                                                                                                                                                                               |
