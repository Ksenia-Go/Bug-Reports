# BUG-03 — Текст-подсказка не исчезает при вводе даты

| Параметр                  | Значение                                                                                                                                                                                                                                |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ID                    | BUG-03                                                                                                                                                                                                                                 |
| Заголовок             | Текст-подсказка в поле «Когда хотите забрать» не исчезает при вводе даты                                                                                                                                                                |
| Краткое описание      | В поле «Когда хотите забрать» текст-подсказка не исчезает при попытке ввести собственную дату.                                                                                                                                          |
| Предусловие           | —                                                                                                                                                                                                                                       |
| Шаги воспроизведения  | 1. Открыть главную страницу сайта https://guru.qahacking.ru/ <br> 2. Перейти во вкладку «О нас» <br> 3. Прокрутить страницу вниз до формы бронирования питомца <br> 4. Попытаться ввести собственную дату в поле «Когда хотите забрать» |
| Фактический результат | Текст-подсказка не исчезает при вводе даты. Перед вводом даты необходимо удалить текст-подсказку вручную.                                                                                                                               |
| Ожидаемый результат   | Текст-подсказка исчезает автоматически при начале ввода собственной даты.                                                                                                                                                               |
| Severity              | Minor                                                                                                                                                                                                                                   |
| Priority              | Low                                                                                                                                                                                                                                     |
| Окружение             | Windows 11 Pro, Яндекс Браузер 26.8.1.966                                                                                                                                                                                               |
