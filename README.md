# Bug Reports

Учебный проект по поиску и оформлению дефектов в веб-приложении.

## Тестируемый сайт

QA Hacking Guru — учебный сайт для практики тестирования.

🔗 https://guru.qahacking.ru/

## О проекте

В рамках проекта проведено исследовательское тестирование сайта и оформлены найденные дефекты в виде отдельных баг-репортов.

Цель проекта — отработать навыки:

* поиска и воспроизведения дефектов;
* составления понятных шагов воспроизведения;
* описания фактического и ожидаемого результата;
* определения Severity и Priority;
* оформления баг-репортов в формате, приближенном к рабочему.

## Содержание

Проект содержит 7 баг-репортов, включающих функциональные, визуальные и контентные дефекты.

Каждый баг-репорт содержит:

* ID и заголовок;
* краткое описание;
* предусловия;
* шаги воспроизведения;
* фактический результат;
* ожидаемый результат;
* окружение;
* Severity;
* Priority;
* скриншот дефекта.
