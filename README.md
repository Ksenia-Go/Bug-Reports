# Bug Reports

Учебный проект по поиску и оформлению дефектов в веб-приложении.

## Тестируемый сайт

QA Hacking Guru — учебный сайт для практики тестирования.

🔗 https://guru.qahacking.ru/

## Содержание

Проект содержит 7 баг-репортов, включающих функциональные, визуальные и контентные дефекты.

Каждый баг-репорт содержит:

* ID и заголовок;
* краткое описание;
* предусловия;
* шаги воспроизведения;
* фактический результат;
* ожидаемый результат;
* окружение;
* Severity;
* Priority;
* скриншот дефекта.

## Окружение

* OS: Windows 11 Pro
* Browser: Яндекс Браузер 26.8.1.966
