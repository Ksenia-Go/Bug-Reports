# BUG-06 — Опечатка в названии блока «Популярное»

| Параметр                  | Значение                                                                                                                                                     |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ID                    | BUG-06                                                                                                                                                   |
| Заголовок             | Опечатка в названии блока «Популярное» в разделе «Блог Джесси»                                                                                               |
| Краткое описание      | В разделе «Блог Джесси» название блока «Популярное» отображается с опечаткой.                                                                                |
| Предусловие           | —                                                                                                                                                            |
| Шаги воспроизведения  | 1. Открыть главную страницу сайта https://guru.qahacking.ru/ <br> 2. Перейти во вкладку «Блог Джесси» <br> 3. Прокрутить страницу вниз до блока «Популярное» |
| Фактический результат | Название блока отображается как «Пупулярный».                                                                                                                |
| Ожидаемый результат   | Название блока отображается корректно — «Популярное».                                                                                                        |
| Окружение             | Windows 11 Pro, Яндекс Браузер 26.8.1.966                                                                                                                    |
| Severity              | Minor                                                                                                                                                        |
| Priority              | Low                                                                                                                                                          |
