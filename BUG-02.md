# BUG-002 — Поле «Телефон» принимает не более 10 цифр вместо заявленных 12

| Параметр                  | Значение                                                                                                                                                                                     |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ID                    | BUG-02                                                                                                                                                                                      |
| Заголовок             | Поле «Телефон» принимает не более 10 цифр вместо заявленных 12                                                                                                                               |
| Краткое описание      | В форме бронирования питомца указано ограничение до 12 цифр для номера телефона, однако поле позволяет ввести только 10 цифр.                                                                |
| Предусловие           | —                                                                                                                                                                                            |
| Шаги воспроизведения  | 1. Открыть главную страницу сайта https://guru.qahacking.ru/ <br> 2. Перейти во вкладку «О нас» <br> 3. Прокрутить страницу вниз до формы бронирования питомца <br> 4. Ввести номер телефона |
| Фактический результат | Поле позволяет ввести только 10 цифр или 8 цифр после автоматически отображаемого кода +7.                                                                                                 |
| Ожидаемый результат   | Поле позволяет ввести номер телефона длиной до 12 цифр, как указано в интерфейсе.                                                                                                            |
| Окружение             | Windows 11 Pro, Яндекс Браузер 26.8.1.966                                                                                                                                                    |
| Severity              | Major                                                                                                                                                                                        |
| Priority              | High                                                                                                                                                                                         |
